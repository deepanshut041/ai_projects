# Document Assistant — complete course outline

Saved before substantive lesson authoring on 26 October 2026. This is one ordered written route through all seven project phases. The reader first judges one answer, then learns each numerical and systems mechanism needed to build and evaluate that answer under a memory budget.

First session: Lessons 1–4, stopping with a written answer contract and an illustrative memory budget. No model download is needed for any teaching reference. Full-model implementation starts separately with phase 00 compatibility.

## Teaching and implementation boundary

Every example is complete, executable and tested in a disposable directory. Numerical fixtures are authored arithmetic, not measured Gemma answers or speedups. The real project source remains its existing scaffold: status/check/show-config work, prepare-data/quantize/evaluate/answer remain explicit exit-2 actions. Runtime compatibility, weights, public QA membership, model scores, device measurements, saved model service and learner review remain pending.

The course introduces all helpers before their first call, uses the same tiny Lumen manual for document contracts, and keeps prompt/weights/cache changes separately controlled. AWQ/GPTQ/KIVI explain mechanisms with explicit departures; their toy references are not full implementations or proof of support.
