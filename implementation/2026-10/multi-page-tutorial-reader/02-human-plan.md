# Multi-page tutorial reader

A tutorial should be one place to learn from many editable Markdown files. Preserve existing chapters and lesson manifests, and present each chapter as a short page in the current site with a contents menu and previous/next links. Include workbook and whiteboard material in that menu. Keep the complete lesson for download/printing.

This is authorized local site implementation. Dashboard is a read-only reference; no dependency migration, model work, commits or publication. Completion requires preserved source bytes, all content/controls reachable, passing content/build/browser checks at root and repository prefixes, and desktop/mobile inspection.
