# Read the final comparison without moving the goalposts

## Give the final average its denominator

Mean absolute error adds the magnitude of every aligned residual, preventing positive and negative misses from cancelling. For the selected model, total absolute error is five hundred and forty eight thousand, six hundred and ninety eight point one one one nine. Dividing by four thousand, three hundred and seventy five recorded hours gives one hundred and twenty five point four one six seven rentals per hour. The denominator is the observed evaluation population, not every expected calendar slot. This definition stayed fixed before the test was opened, so it can be compared honestly with the prior validation score.

## Keep three error questions beside each other

Absolute error answers average miss magnitude. Root mean squared error squares each miss before averaging, then takes the root to return to rental units. Here it is one hundred and seventy four point four seven. Mean signed error is negative one hundred and eleven point three six, showing substantial underprediction. These numbers answer different questions. A near zero signed average could hide equally large positive and negative misses, while squaring makes large errors more influential. Keeping all three prevents one attractive number from substituting for the task. None is a calibrated uncertainty interval or a measure of downstream inventory value.

## Keep the real ranking reversal visible

The group predictor won validation with mean absolute error ninety one point five seven, ahead of the retained forest at ninety nine point eight three. Later, the group score rises to one hundred and twenty five point four two, while the forest scores one hundred and three point six five. Interaction regression also scores below groups on the final hours, at one hundred and eleven point three zero. All seven rows share the same final membership and already selected policies. This is a real negative finding about the original selection’s transfer. Hiding the reversal would make the project easier to celebrate and harder to understand.

## Align identities before reducing errors

The result comes from row aligned forecasts. Each prediction carries the same record, target time and issue time as its observation. The scorer refuses missing, duplicated or reordered identities before reducing errors. Independent verification checks all thirty thousand, six hundred and twenty five final forecasts, the error arithmetic and the slice totals. Group predictions are also recomputed directly from the original training observations. Passing these checks establishes the measured values and fixed execution, while a disappointing score remains disappointing. Correct code and strong later forecasting are separate conclusions.

## Read complexity within its measured scope

The group artifact uses five thousand, six hundred and forty JSON bytes, while the forest uses about sixteen million. Historical fitting took about zero point zero one three six seconds for groups and zero point six seven six two for the forest. Final saved snapshot replay took roughly zero point zero two eight eight and zero point one eight four two seconds for the full batches. These costs belong to this local implementation and machine. Storage bytes are not peak memory, and batch snapshot traversal is not optimized per request production latency. Cost can inform another decision without rewriting the fixed quality comparison.

## Selection history is different from a new choice

The application keeps the original selected badge on groups, preserving the distinction between the development decision and the final finding. This does not force deployment of a model regardless of evidence. Choosing the forest next can be reasonable, but the choice now uses knowledge from this test. A new independent performance claim needs new held out evidence. The task also never supplied an operational error threshold or the cost of missed demand versus idle bicycles. Beating a global mean therefore does not establish planning readiness. The result supports a more informed next conversation, not an invented acceptance gate.
