# Learning points to carry into the implementation

A document assistant is an evidence contract. A plausible fact and a real citation ID are individually insufficient; the cited text must establish every material claim. A refusal can be correct when the document lacks a fact, and wrong when the fact was supplied. Parsing, packing, retrieval, generation and evaluation can each cause a failure, so retain their boundaries instead of assigning every error to the model.

Quantization replaces a floating value with a finite reconstruction grid. Scale fixes spacing, zero point fixes which integer reconstructs zero, rounding chooses a level and clipping handles values outside the range. Payload bits omit scales, offsets, padding, higher-precision tensors and runtime workspaces. A list of integer objects is a numerical reference, while an actual packed format is a storage contract with shape/count and decoding rules.

The effect of a weight error depends on the input: output error is E x. A calibration Gram matrix records uncentered input second moments so equal weight MSE can have unequal output reconstruction loss. Diagonal channel scaling preserves the float operation only when the input is inversely scaled; after nonlinear quantization it can improve or worsen loss. Correlated channels allow continuous compensation, but subsequent discrete rounding and poorly observed directions limit the argument. These mechanisms explain AWQ/GPTQ ideas without establishing that a particular exporter supports the selected model.

Weights and KV cache have different lifetimes and variables. Cache storage depends on actual KV heads, dimensions, owners, retained tokens, batch, types, groups and residual/allocation policy. Key errors alter attention probabilities; value errors alter the mixed content under fixed probabilities. Hybrid/shared architectures require inspected ownership rather than a uniform layer multiplier. Less disk storage does not establish lower total live memory or higher throughput.

A comparison is defined by the factors held fixed. Prompts, tokenization, runtime, placement, cache policy, decoding and question membership belong in the identity alongside weight format. Timing needs observable events and actual work counts. Quality needs exact IDs, explicit denominators and retained failures. Development selection and final assessment are separate; an empty feasible set is a valid result, and uncertainty must respect document-level dependence.

A reloadable artifact is an immutable generation with identity, integrity and compatibility evidence. Atomic publication, crash durability and verified fallback are separate properties. The service must own/reset request state and expose backend/artifact context. A fixture response and a rendered tutorial are useful checks with explicit scopes; neither proves real inference or a completed learner milestone.
