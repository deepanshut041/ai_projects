## Exit questions for the complete project

Can another person reconstruct the accepted source/runtime/template, acquire permitted data/model bytes, reproduce conversion and the exact comparison membership, inspect failures, load the chosen generation and ask a supported/unavailable question after restart? Can they identify which bytes/policy changed between each pair and which conclusions the evidence cannot support? If not, record the missing link precisely.

A good report can show a negative result: a compressed candidate may fail support quality, be slower, or lack runtime support. Preserve that outcome under its original constraints. Do not equate tutorial completion, passing author references, a valid scaffold package, a model benchmark, learner mastery and an accepted local application.
