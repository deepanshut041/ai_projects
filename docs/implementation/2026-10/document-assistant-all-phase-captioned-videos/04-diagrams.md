# Visual direction

Match Attention's editable clean16:9 teaching boards: a clear question, limited information per frame, source-faithful numbers/units, displayed helper definitions before callers, cue-bound highlights and a changed case. Use number grids, matrix/scalar arithmetic, comparisons, state/identity timelines and complete code pages where they answer the lesson's problem. Avoid decorative image generation for code/maths. Inspect real rendered stills and finished sound/video; static text alone cannot prove synchronization or audibility.
