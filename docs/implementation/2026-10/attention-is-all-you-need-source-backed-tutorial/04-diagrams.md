# Visual meaning and provenance

Fifteen original PNG figures are copied verbatim from the project's existing runs/attention-visuals outputs. attention_visuals.py is the preserved editable drawing source; the course captures its source identity and includes the controlled matrix fixtures. Figures teach weighted values, individual matrix cells, unprojected attention, projection bias, head layout, padding/causal masking, rectangular cross-attention, path parity and gradients.

Two small Mermaid diagrams show computation: query/key comparison produces normalized weights which mix values, and cross-attention takes queries from target representations while source representations provide keys/values. These arrows describe tensor dependence, not learner prerequisites or claims about trained linguistic alignments.

Browser review checks actual diagrams, equation rendering, label visibility and local scrolling. Saved figures show synthetic/controlled inputs. No upstream image was copied and no new narrated media or trained alignment picture is created.
